# What is Tutor Court?

Tutor Court is an online platform that connects students with tutors for online classes. It is a platform that helps students find tutors for online classes. The platform is built with Next.js, Video SDK, PayloadCMS, MongoDB and TypeScript.

# Understanding the project

1. both students, parent and tutors have thier own dashboard route.
2. We support both NGN & USD.
3. Tutors create a class an invite a parent and the parent can add their child to the class durring onboarding or the pparent classes page.
4. We have subjects and tutors teach those subjects by creating a class, inviting a parent or student and creating and updated the schedule for thier classes.

# Skills

## UI / Design work

For ANY UI task — building or redesigning a component, page, screen, or section — invoke these skills in order before writing code:

1. **`ui-ux-pro-max`** — sets the elite quality bar (visual direction, typography, spacing, motion, accessibility, responsive). Invoke first, always.
2. **`frontend-design`** — translates the direction into production-grade, aesthetically distinctive React/Next.js code. Invoke after `ui-ux-pro-max`.
3. **`emil-design-eng`** — applies Emil Kowalski's craft details: micro-interactions, spring physics, the invisible polish that makes interfaces feel right. Invoke when implementing motion, hover states, or any interactive detail.

These three skills stack. Run them in order on every UI task; do not skip one because the task seems small.

## Idea exploration

**`grill-me`** — invoke this skill when the user (or you) has a loose, unclear, or under-specified idea and needs to think it through before designing or building. It runs a structured interview in rounds until every key decision is settled. It writes no files and produces no plan — only clarity.

Trigger automatically when the user says things like:
- "I'm thinking about…" followed by something vague
- "How should we approach…"
- "What's the best way to…" (open-ended, not a specific implementation question)
- "We need to figure out…"
- Anything that reads like an idea that hasn't been worked out yet

Do not invoke `grill-me` when the user has already given a clear, specific task.
